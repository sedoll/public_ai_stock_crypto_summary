# AI Stock & Crypto Summary Bot

## Links

- Telegram: https://t.me/osc_news
- Threads: https://www.threads.com/@ai_stock_crypto_summary_news?hl=ko

## 소개

주식과 코인 관련 Telegram 채널, 뉴스, YouTube 영상 내용을 모아 AI로 요약해 발행하는 자동화 봇입니다.

매일 시장 관련 메시지와 콘텐츠를 정리해 핵심 흐름을 빠르게 볼 수 있도록 만들었습니다. 요약 결과는 Telegram과 Threads에 게시됩니다.

## Why

주식과 코인 정보는 여러 채널과 플랫폼에 흩어져 있고, 하루에 쌓이는 양도 많습니다.

이 봇은 반복적으로 확인해야 하는 시장 뉴스, 채널 메시지, 영상 내용을 자동으로 모아 요약하고, 짧은 시간 안에 핵심 흐름만 볼 수 있도록 만들었습니다.

## Built With

- Python: 데이터 수집과 API 서버 구현
- n8n: 수집, 요약, 발행 자동화 workflow 구성
- MariaDB: 수집 데이터, 요약 결과, 발행 로그 저장
- Docker Compose: 로컬 실행 환경 구성
- Telegram API: 메시지 수집과 요약 발행
- Threads API: 요약 발행
- YouTube Data API: 영상 정보 수집
- AI 모델 API: 수집한 텍스트 요약

## Issues & Fixes

### 긴 입력으로 인한 AI 요약 실패

여러 채널의 메시지와 영상 자막을 한 번에 요약하면 입력이 길어져 AI 요청이 실패하거나 응답 시간이 길어지는 문제가 있었습니다.

해결 방법:

- 채널 단위로 나눠 처리했습니다.
- 요약에 불필요한 날짜 prefix 같은 텍스트를 제거했습니다.
- 입력 길이에 제한을 두고 최근 내용 중심으로 요약하도록 조정했습니다.
- AI 요청 실패 시 재시도할 수 있도록 workflow를 구성했습니다.

### 플랫폼별 발행 실패 추적이 어려움

처음에는 AI 요약 결과를 만든 직후 바로 발행하는 구조라서, Telegram은 성공했지만 Threads만 실패한 경우처럼 플랫폼별 상태를 관리하기 어려웠습니다.

해결 방법:

- AI 요약 결과를 먼저 저장했습니다.
- Telegram, Threads 같은 플랫폼별 발행 결과를 따로 기록하도록 분리했습니다.
- 특정 플랫폼만 다시 발행하거나 실패 여부를 확인하기 쉽게 구조를 바꿨습니다.

### Threads 글자 수 제한

Threads는 일반 본문 길이에 제한이 있어 긴 요약을 그대로 올리면 내용이 잘리는 문제가 있었습니다.

해결 방법:

- 본문에는 짧은 소개 문구를 넣었습니다.
- 긴 요약은 Threads에서 지원하는 긴 텍스트 첨부 방식으로 분리해 발행했습니다.

### 수집 데이터 중복 처리

같은 날짜의 데이터를 다시 수집하거나 같은 영상을 다시 처리할 때 중복 저장될 수 있는 문제가 있었습니다.

해결 방법:

- 수집 기준 날짜와 콘텐츠 ID를 기준으로 중복 여부를 확인했습니다.
- 이미 처리한 데이터는 다시 발행하지 않도록 상태를 저장했습니다.

### 운영 설정 변경의 어려움

처음에는 수집 대상이나 발행 여부를 코드에 직접 넣는 방식이라 채널 추가, 비활성화, 플랫폼별 발행 설정 변경이 번거로웠습니다.

해결 방법:

- 수집 대상과 발행 옵션을 DB에서 관리하도록 바꿨습니다.
- 채널별로 Telegram 또는 Threads 발행 여부를 선택할 수 있게 구성했습니다.
